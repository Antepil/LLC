# MATLAB Neural ODE 仿真验证：已确认方案

确认日期：2026-10-24（Asia/Shanghai）。

状态：设计已归档，并已实现模型导出、MATLAB 原生前向与积分、同门极回放、冷启动/预热独立闭环、结果保存及自动测试。尚未使用真实训练模型完成正式基线，因此本文档及实现不表示模型预测精度已通过验证。

## 1. 目标与范围

搭建完整 MATLAB/Simulink 验证流程，支持同门极回放和独立闭环对照。Python 负责训练模型与导出；MATLAB 原生完成网络前向计算、物理状态积分、PI/PFM 控制、事件处理、指标计算及绘图。

范围包括模型导出接口、MATLAB 模型加载和计算、状态积分、现有 PI/PFM 接入、波形对比及结果保存。实施顺序为模型一致性、同门极回放、冷启动闭环、预热状态交接、报告与使用文档。

没有训练模型时，可以使用确定性测试模型验证计算和流程，但不得据此宣称真实波形预测准确。

## 2. 模块边界

| 模块 | 职责 |
| --- | --- |
| Python 模型导出 | 从选定 checkpoint 导出网络及训练时使用的尺度、模型契约和对照样例 |
| MATLAB 配置加载 | 读取验证配置及其引用，检查完整性、路径和契约 |
| MATLAB 网络前向 | 原生执行 Linear + SiLU 网络，输出四个归一化状态导数 |

闭环信号关系：参考电压 → PI → PFM → 四路门极 → 电路或 Neural ODE + 积分器 → 输出电压采样与滤波 → PI。

## 3. 模型导出与数值契约（Q2、Q3、Q6）

采用一个 MAT 文件携带网络权重、偏置、结构和归一化参数。MATLAB 原生完成前向计算，不逐积分步调用 Python，也不要求使用深度学习工具箱执行当前网络。

导出接口同时保存一组输入及对应 Python 网络输出，供 MATLAB 数值一致性检查。每层权重布局、偏置形状、激活函数和文件内部 schema 的精确定义应在实现导出接口时明确，并通过两端一致性测试验证。

首版固定负载为 2.304 Ω。负载不属于网络输入；模型文件、参考数据或验证工况与这一契约不一致时应显式报错。不能通过修改 MATLAB 负载配置获得跨负载支持。

物理状态顺序为 `[i_Lr, v_Cr, i_Lm, v_o]`，单位为 `[A, V, A, V]`。网络输入顺序为四个归一化状态、`[Q1_A_high, Q2_A_low, Q3_B_high, Q4_B_low]`、归一化 Vin。

MATLAB 使用物理时间 t（秒）积分物理状态 x。设训练状态尺度为 S，电压归一化基准为 V_base，时间基准为 T_base，则：

```text
z = x ./ S
u = [z; gates; Vin / V_base]
dx_dt = (S / T_base) .* f_theta(u)
```

尺度及基准全部从导出模型读取，不在验证时重新拟合。V_base 是输入归一化基准，与控制目标 Vref 不同。积分器的输出电压以伏特送给控制器，避免重复换算时间或状态尺度。

## 4. 同门极回放（Q4）

直接读取已有 MATLAB 参考轨迹，使用其第一个节点的状态、Vin 和准确门极事件驱动 Neural ODE。随后全程自由预测，不再注入参考状态；参考状态仅用于误差计算和绘图。

使用完整参考轨迹评估累积误差。缺失必要字段、门极事件覆盖不完整或负载不匹配时显式报错，不自动用固定网格门极近似替代准确事件。

参考轨迹路径存在不代表数据契约已通过检查；加载器必须检查文件内容、时间覆盖和初值。已有参考轨迹沿用其真实工况，不强行改写为独立闭环基线工况。

## 5. 独立闭环（Q5）

复用现有 MATLAB PI/PFM 实现。参考电路支路反馈自身的输出电压，Neural ODE 支路反馈自身预测的输出电压。两套控制器采用相同配置和初始条件，但内部状态独立演化。

沿用现有电压滤波、启动斜坡、频率变化率限制、死区和相位逻辑。控制参数统一从被引用的配置读取，消除验证配置中重复填写初始频率等参数的双重来源。

同输入回放误差与独立闭环差异分别统计。独立闭环中，反馈差异会引起频率及门极时刻差异，不将其简单解释为同输入条件下的模型误差。

## 6. 积分与门极事件（Q7）

首版 MATLAB 沿用 ode23t。回放按记录的准确门极事件分段积分；独立闭环由现有 PFM 事件驱动 Simulink 更新门极。

门极在事件之间保持常量，不能线性插值；四个物理状态在切换时保持连续。仅设置较小最大步长不能替代门极事件处理。

通过减小最大步长、收紧容差检查数值收敛。现有配置的步长和容差为起始设置，不能直接视为已验证精度。数值一致性和积分收敛检查独立于模型预测精度验收。

## 7. Vin 与目标电压信号（Q8、Q11、Q13）

### 7.1 Vin

支持恒定 Vin 和明确的时间—电压序列。单位分别为秒和伏特。序列采用线性插值，与 Python rollout 的约定一致：相邻节点之间按时间比例计算，节点及首末端点使用给定值。

时间必须严格递增，时间和电压必须有限，电压必须为正，序列必须覆盖完整仿真区间。不允许越界外推。回放从参考轨迹读取 Vin；独立闭环将同一 Vin 信号送给两条支路。

使用文档必须提供恒定和时变 Vin 示例，明确时间轴、端点规则、覆盖范围及非法输入报错。扰动幅值与发生时刻尚未确定，不预设为正式验收工况。

### 7.2 目标电压

支持恒定值和分段常值阶跃序列，采用前值保持。阶跃在指定时刻生效，由 PI 在下一个控制采样时刻读取。两条闭环支路使用相同参考信号。

冷启动保留现有参考启动斜坡；预热交接后不重新施加启动斜坡。文档必须区分 Vin 的线性插值与目标电压的前值保持。

### 7.3 预热与评估时间轴

预热阶段 Vin 和目标电压保持恒定。通过稳态检查并完成交接后，才施加评估阶段的输入变化。

设预热结束时刻为 t_w，评估曲线使用局部时间 t_eval = t - t_w，以交接时刻为零点。控制器和调制器继续使用连续的仿真时间及相位，不因评估时间归零而重新启动。冷启动时 t_eval = t。

配置应分别表达预热工况、预热时长、交接后输入曲线及评估时长。评估曲线起点与预热工况不同即为交接时施加的扰动，必须显式配置和记录。

## 8. 冷启动与预热启动（Q9—Q11）

### 8.1 冷启动

两条支路使用相同的零电路状态，并复用现有控制器和调制器的启动初值。参考斜坡按现有逻辑运行，评估覆盖完整启动过程。

### 8.2 预热启动

先运行参考电路到配置指定的预热时刻。交接前要求通过周期稳态检查，并确认输出电压达到目标；复用现有稳态判定逻辑。若未通过，报告预热失败，不自动延长预热，也不将未稳态状态视为稳态启动。

通过检查后，参考支路继续运行，将交接时刻的完整状态复制给 Neural ODE 支路，包括：

- 四个电路状态。
- 滤波电压、PI 积分量及控制器继续运行所需的其他状态。
- 当前频率、调制相位、当前及待导通桥对。
- 控制更新时间、待处理门极事件及其时间等调度状态。

时间、相位和待处理事件保持连续，参考斜坡进度不重置。交接后两条支路分别反馈自身输出，独立运行。

仅复制四个电路状态不足以恢复闭环。实现必须验证交接时没有重复或遗漏事件，并定义事件重合时的一致交接边界。

预热阶段不计入 Neural ODE 预测误差；从状态交接后开始统计。此模式评估从共同预热状态出发的预测能力，不能替代冷启动验证。

## 9. 首批基线与指标（Q12、Q14）

| 参数 | 已确认初始值 |
| --- | --- |
| Vin | 400 V |
| 目标电压 | 48 V |
| 负载 | 2.304 Ω |
| 冷启动评估时长 | 5 ms |
| 预热时长 | 5 ms，必须通过稳态检查 |
| 预热交接后评估时长 | 5 ms |

这些值应可配置。第一批独立闭环基线使用恒定工况；扰动示例可写入文档，正式实验的幅值和时刻待用户确定。

四个状态分别报告 RMSE、按训练状态尺度归一化的 RMSE、最大绝对误差，并展示全程波形和末段纹波对比。闭环额外报告输出电压跟踪误差及末段均值偏差。

报告中应明确每个指标的比较对象：状态预测误差比较模型与参考电路；跟踪误差比较各支路输出与实际参考信号。冷启动、预热启动、回放和独立闭环分别标识，不混合统计。

暂不设置未经确认的模型精度通过阈值，待真实模型首轮结果后由用户确定。已有配置中的频率和门极时序指标并非本轮确认的核心验收项；若保留门极时间误差，必须先明确边沿匹配及边沿数量不同的处理规则。
